Privacy Policy for ERP-Backup

Last updated: November 3, 2026

Purpose

ERP-Backup is a personal backup utility that uses rclone to upload, verify and restore encrypted ERP backup files in the owner's Google Drive account.

Google Drive Access

The application requests Google Drive access to create and manage its backup files. It does not require access to unrelated personal files.

Data Storage

OAuth credentials are stored locally on the owner's computer. Backup content is encrypted locally before uploading to Google Drive.

Data Sharing

The application is for personal use. Google Drive data is not sold or shared for advertising.

Data Deletion

The owner manages backup retention and can delete backup files from Google Drive.

Contact

For questions, visit the project's GitHub repository.
